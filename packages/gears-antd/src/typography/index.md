# Typography 排版

常用于展示明细

## 基本用法

`LabelRow` 包裹 `Label` 使用，用于类似表格形式的信息展示

`LabelRow` 表示一行，`Label` 表示一行中的一组标签（包含标签名和标签值），一行中可以有多组标签。
